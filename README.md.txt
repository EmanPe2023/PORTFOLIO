# EMAN SARHAN Portfolio

## Overview
This is a portfolio project for a fashion e-commerce website built using **HTML** and **CSS**. The site showcases responsive web design, interactive buttons, product sections, and a clean UI/UX.

## Features
- Fully responsive layout
- Product showcase with images, colors, and sizes
- Interactive buttons for shop actions
- Sectioned layout for promotions, collections, and deals
- SEO-friendly HTML structure with descriptive `alt` texts
- Fonts from Google Fonts (Poppins)
- Basic UI/UX design principles

## Skills Demonstrated
- HTML5 & CSS3
- Responsive Web Design
- Flexbox & Grid layouts
- Typography and color design
- Basic SEO optimization
